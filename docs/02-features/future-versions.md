# Fonctionnalités différées — V2 à V4

Ce document conserve les intentions du cahier des charges sans leur donner artificiellement des contrats implémentables avant le MVP.

## V2 — Gestion de projet
Import PDF/Markdown/image et documents produits ; permissions/versionnement ; base de connaissances validées ; Kanban ; jalons/planning ; équipes réutilisables ; recherche ; tableau de bord consolidé.

## V3 — Développement parallèle
Git worktrees multiples avec allocations concurrentes ; dépendances entre tickets et blocages calculés ; revue croisée approfondie ; suites de tests automatiques ; relecture contextuelle de décisions validées ; gestion des incidents.

## V4 — Autonomie avancée
Délégation structurée, débats techniques et arbitrages, workflows configurables, automatisations événementielles bornées, rapports et fournisseurs additionnels.

## Garde-fous inchangés
Droits explicites, provenance des actions, coûts et limites d'exécution, pas de propagation arbitraire des privilèges, approbations sensibles, traçabilité.

## Ne pas développer prématurément
Les schémas et endpoints dédiés à ces versions ne sont pas requis pour les tâches V1-A/V1-B, sauf extension indispensable et justifiée.
