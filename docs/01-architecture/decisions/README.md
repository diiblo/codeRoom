# Architecture Decision Records (ADR)

Un ADR passe par `proposé`, `accepté`, `supplanté` ou `rejeté`. **Seul `accepté` vaut décision**.

- [ADR-001 — Monolithe modulaire et stockage local](ADR-001-monolith.md) — proposé.
- [ADR-002 — Contrôle d'exécution, permissions et confinement](ADR-002-execution-security.md) — accepté, preuve d'implémentation requise.
- [ADR-003 — Stratégie des adaptateurs fournisseurs](ADR-003-adapters.md) — proposé.
- [ADR-004 — Plateforme supportée au lancement](ADR-004-platform-support.md) — accepté.
- [ADR-005 — Exposition de l'interface locale](ADR-005-loopback-ui.md) — accepté.

Toute acceptation renseigne : date, décideur, alternatives examinées, compromis, documents/tâches impactés. Les décisions encore ouvertes figurent dans [le registre](../../00-product/decisions-open.md).
